#  DepTaskNet

This repository is the official implementation of the paper [**"Neural Combinatorial Optimization for  Multiobjective Task Offloading in Mobile Edge Computing"**](https://ieeexplore.ieee.org/abstract/document/10908871). *IEEE Transactions on Vehicular Technology*, 2025.

## Quick Start

### 1.Environment setup
- python 3.8.x
- pytorch 1.8.1+cu111

### 2.Reproduce result in paper

To reproduce the result in the paper, please run:
```python
python PPO_2obj/PPOMain.py
```
or
```python
python PPO_2obj_mix/PPOMixMain.py
```

## Introduction

### 1. Project Structure(PPO_2obj for example)
- `PPOMain.py`: The main file for training and testing the PPO model for multi-objective task offloading.
- `PPORunner.py`: The runner file that manages the PPO training process and testing.
- `PPOModel.py`: The file defining the DepTaskNet model architecture.
- `PPOEnv.py`: The environment file that simulates the mobile edge computing scenario for task offloading.
- `PPODAGLoader.py`: The data loader file that loads datasets from `.gv` files.(If use Preprocessed data, this file can be ignored)
- `utils.py`: The utility functions(such as creating a logger, copying source files, and plotting results) used in the project.

### 2. Dataset

Our dataset is generated by [DAGGEN](https://github.com/frs69wq/daggen), and the raw data is stored as text files in `.gv` format. 
To speed up data loading, we also provide pre-processed data for specific bandwidth settings.
